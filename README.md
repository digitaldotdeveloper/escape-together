# ESCAPE TOGETHER

A two-player online co-op physics comedy game that runs in a browser.
Two friends, one collapsing hotel, and physics that will betray you both.

**Play: https://digitaldotdeveloper.github.io/escape-together/**

One of you presses CREATE ROOM and sends the invite link; the other opens it.
No accounts, no download, nothing to install.

This repository holds the built game only. On a static host there is no server
to run the simulation, so the browser that created the room runs it and the two
players are connected directly to each other; a public broker introduces them
and then carries none of the traffic.
